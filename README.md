# 🏡 House Price Prediction using Machine Learning

An end-to-end Supervised Machine Learning project focused on analyzing real estate data and predicting house prices using both **Regression** (continuous price prediction) and **Classification** (predicting high vs. low price category) models.

---

## 📌 Project Overview

Understanding the key drivers of house valuation is essential for buyers, sellers, and real estate professionals. This project covers the full machine learning lifecycle:
- **Exploratory Data Analysis (EDA)** & Data Visualization
- **Data Preprocessing & Encoding** (Categorical variable transformation)
- **Feature Scaling** (Standardization/Normalization)
- **Model Training & Comparison** (Linear Regression, Decision Tree, Random Forest, etc.)
- **Model Evaluation** (RMSE, MAE, R² score for Regression; Accuracy, Precision, Recall, F1 for Classification)

---

## 📊 Dataset Description

The dataset (`House Price Prediction Dataset.csv`) includes features such as:
- **Area / Square Footage**
- **Bedrooms & Bathrooms**
- **Floors & Year Built**
- **Location & Condition**
- **Garage Availability**
- **Price (Target variable)**
